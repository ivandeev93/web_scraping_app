# Web Scraping App

Парсер данных о новых автомобилях с сайта [Kolesa.kz](https://kolesa.kz/).

Приложение автоматически собирает информацию о моделях автомобилей, их ценах и технических характеристиках и сохраняет полученные данные в CSV-файл.

## Возможности

* Парсинг списка новых автомобилей с Kolesa.kz
* Обработка 18 страниц каталога
* Получение названия модели
* Получение минимальной и максимальной цены
* Получение основных технических характеристик:

  * тип двигателя
  * объём двигателя
  * мощность
  * коробка передач
  * тип привода
  * количество комплектаций
* Сохранение результатов в `auto.csv`
* Обработка электромобилей с отсутствующим объёмом двигателя

## Используемые технологии

* **Python 3**
* **Requests** — выполнение HTTP-запросов
* **BeautifulSoup 4** — парсинг HTML
* **CSV** — сохранение результатов

## Установка

Клонируйте репозиторий:

```bash
git clone https://github.com/ivandeev93/web_scraping_app.git
cd web_scraping_app
```

Создайте виртуальное окружение:

```bash
python -m venv venv
```

Активируйте виртуальное окружение.

### Windows

```bash
venv\Scripts\activate
```

### Linux / macOS

```bash
source venv/bin/activate
```

Установите зависимости:

```bash
pip install requests beautifulsoup4
```

## Запуск

Запустите основной скрипт:

```bash
python main.py
```

После выполнения скрипта в корневой директории будет создан или обновлён файл:

```text
auto.csv
```

## Формат данных

Результат сохраняется в CSV с разделителем `;`.

Файл содержит следующие столбцы:

| Поле                      | Описание                          |
| ------------------------- | --------------------------------- |
| `Наименование`            | Название модели автомобиля        |
| `Начальная цена`          | Минимальная цена                  |
| `Максимальная цена`       | Максимальная цена                 |
| `Тип двигателя`           | Тип двигателя                     |
| `Объём двигателя`         | Объём двигателя                   |
| `Мощность двигателя`      | Мощность двигателя                |
| `Коробка передач`         | Тип коробки передач               |
| `Тип привода`             | Привод автомобиля                 |
| `Количество комплектаций` | Количество доступных комплектаций |

Пример:

```csv
Наименование;Начальная цена;Максимальная цена;Тип двигателя;Объём двигателя;Мощность двигателя;Коробка передач;Тип привода;Количество комплектаций
Toyota Camry XV80;16 499 000;26 190 000;Бензин/Гибрид;2,5 л;186-204 л.с.;Автомат/Вариатор;Передний;5 комплектаций
Chevrolet Tracker;10 240 000;10 740 000;Бензин;1-1,2 л;115-132 л.с.;Автомат;Передний;4 комплектации
```

## Как работает парсер

Скрипт выполняет следующие действия:

1. Создаёт CSV-файл и записывает заголовки.
2. Последовательно отправляет GET-запросы к страницам каталога автомобилей.
3. Получает HTML-код страницы.
4. Передаёт HTML в BeautifulSoup.
5. Находит карточки автомобилей и извлекает необходимые данные.
6. Разбирает диапазон цен на минимальную и максимальную.
7. Извлекает технические характеристики.
8. Записывает полученные данные в `auto.csv`.

Для каждой страницы используется отдельная HTTP-сессия `requests.Session()`.

* Excel

* Pandas
* Power BI
* других инструментах анализа данных

## Важно

Структура HTML и CSS-классы сайта Kolesa.kz могут измениться. В таком случае селекторы в `main.py` потребуется обновить.

Также перед использованием парсера рекомендуется ознакомиться с правилами и условиями использования сайта и учитывать ограничения на автоматизированные запросы.
